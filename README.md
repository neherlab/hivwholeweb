# HIVWHOLEWEB

https://hiv.neherlab.org

Website for deep sequencing data of longitudinal HIV-1 samples from 11 patients: interactive views of the data, downloads of the data files, and an estimator of the time since infection.

![screenshot](screenshot.png)

## The site

- **Patients** and **Genomic regions**: interactive views of the data of each patient and each genomic region
- **Analyses**: one page per analysis, such as viral load and CD4+ counts, consensus sequences, phylogenetic trees, divergence and diversity, and coverage
- **Data**: downloads of the data files and the precompiled alignments
- **Controls**: the sequencing method and the control experiments
- **Time of Infection**: the estimator of the time since infection
- **People**, **Publications**, **About**

The site was formerly at `hiv.biozentrum.unibas.ch`.
